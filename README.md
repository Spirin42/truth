# truth

https://spirin42.github.io/truth/

Одно слово посреди белой страницы. У его подножия лежит небольшая тень, так
что слово стоит, а не висит. Стоит подвести к нему мышь или палец, и оно
растворяется там, где стояло: сначала расплывается, потом гаснет вместе с
тенью. Через пару секунд слово собирается из тумана на том же месте — до
следующего приближения.

Растворяется оно заранее, ещё до касания: зона вокруг слова — его прямоугольник
с полями, увеличенный в √2 раз по каждой стороне, то есть вдвое по площади.

Сделано по мотивам [sappho · fragment 42](https://spirin42.github.io/sappho/):
та же бумага, тот же шрифт.

## Устройство

Одна страница без зависимостей: вёрстка, стили и логика — в `index.html`,
фавиконка встроена как data-URI. Тень — то же слово, опрокинутое вперёд от
базовой линии, сплющенное, скошенное и размытое. Базовую линию CSS назвать
не умеет, поэтому скрипт находит её при загрузке.

На телефоне слово растворяется и от тапа, и если провести к нему пальцем
с любого места экрана.
